# OpoPace Suite — Showcase

> **All-in-One Study & Productivity Suite**: Smart spaced repetition (**FSRS v4 Engine**), interactive weekly planning grid, physical training companion (**GymPace**), and a unified **Central Hub** with a minimalist Japandi design.

*(Public showcase repository. Source code remains private).*

## Key Features
- **OpoPace (Core App):** **FSRS v4** (*Free Spaced Repetition Scheduler*) algorithm, tactile *Drag & Drop* weekly planner, and topic management.
- **Central Hub:** Unified launcher coordinating all suite applications.
- **GymPace:** Physical companion with an interactive muscle map to balance study and training.
- **Cross-Platform:** Web app, desktop launcher, and mobile support.

## Architecture & Tech Stack
- **Backend & Deployment:** Python, Docker / `docker-compose`, Render (`render.yaml`), and Vercel (`vercel.json`).
- **Algorithm:** FSRS v4 (*Free Spaced Repetition Scheduler*).
