# OpoPace Suite — Showcase

> **Suite integral para opositores**: estudio inteligente con repetición espaciada (**Motor FSRS v4**), planificación semanal interactiva, seguimiento físico (**GymPace**) y **Hub Central** unificado bajo un diseño minimalista Japandi.

*(Repositorio público de presentación. El código fuente permanece privado).*

---

## ✨ Funcionalidades principales
- **OpoPace (App principal):** Algoritmo de repetición espaciada **FSRS v4**, planificación semanal con cuadrícula táctil *Drag & Drop* y gestión de temas.
- **Hub Central:** Lanzador unificado de todas las aplicaciones de la suite.
- **GymPace:** Companion físico con mapa muscular para equilibrar estudio y entrenamiento.
- **Multiplataforma:** Versión web, lanzador de escritorio y soporte móvil.

## 🏗️ Arquitectura y Tecnologías
- **Backend & API:** Python, Docker / docker-compose, despliegue en Render / Vercel.
- **Frontend:** Interfaz moderna responsiva (diseño Japandi).
- **Algoritmo:** FSRS v4 (*Free Spaced Repetition Scheduler*).
